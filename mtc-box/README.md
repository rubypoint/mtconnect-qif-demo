# MTC Box data

This is a partial dataset of the MTC Box data that was created as a collaboration between the MTC and NIST. This directory contains the QIF and the NC data for our purposes. 

The full dataset can be found here: [Design, Manufacturing, and Inspection Data for a Box Assembly - Catalog](https://catalog.data.gov/dataset/design-manufacturing-and-inspection-data-for-a-box-assembly-9b03e)
